UI React (Vite) that talks to the GO agent in `first_agent.go`.

In a terminal:

```bash
cd My_first_Agent_in_go
go run first_agent.go web api
```

In another terminal:

```bash
cd My_first_Agent_in_go/web
npm install
npm run dev
```

Open `http://localhost:5173`. The Vite forwards `/api` to `http://localhost:8080`.
